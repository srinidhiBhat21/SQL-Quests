# SQL Queries

## Overview

This folder contains the SQL script used to solve the business and analytical questions based on the cereals dataset.


# SQL Business Questions
The following 20 SQL questions were used for the Cereals SQL Data Analysis project.

### 1. Add Index

Add an index named `fast` on the `name` column.

### 2. Describe Table Schema

Describe the schema of the table.

### 3. Create a View

Create a view named `see` where users cannot see the `type` column.

First run the appropriate query and then create the view.

### 4. Rename the View

Rename the view `see` as `saw`.

### 5. Count Cold Cereals

Count how many cereals are classified as cold cereals.

### 6. Count Cereals on Shelf 3

Count how many cereals are kept on shelf 3.

### 7. Sort by Ratings

Arrange the table from high to low according to ratings.

### 8. Identify Primary Key

Suggest some column(s) which can be used as a Primary Key.

### 9. Average Calories by Cereal Type

Find the average calories of hot cereal and cold cereal in one query.

### 10. Categorize Calories

Add a new column named `HL_Calories`.

Cereals with calories greater than the average calories should be categorized as `HIGH`, while cereals with calories less than the average should be categorized as `LOW`.

### 11. Cereal Names Beginning with B

List only those cereals whose name begins with `B`.

### 12. Cereal Names Beginning with F

List only those cereals whose name begins with `F`.

### 13. Cereal Names Ending with S

List only those cereals whose name ends with `s`.

### 14. Select HIGH-Calorie Cereals

Select only those records where the `HL_Calories` column is `HIGH`.

### 15. Find Maximum Rating

Find the maximum rating among the cereals.

### 16. Average Rating by Calorie Category

Find the average ratings of cereals categorized as `HIGH` and `LOW` in calories.

### 17. Subqueries

Create two examples of subqueries of your choice.

Give an explanation of each subquery in the SQL script itself using comments with `#`.

### 18. Remove Column

Remove the `fat` column from the table.

### 19. Count Records by Manufacturer

Count the number of records for each manufacturer (`mfr`).

### 20. Select Specific Columns

Select only the following columns:
name
calories
ratings
